# Oney Erge

I build practical tools for local AI and experiments where agents meet physics.
My focus is making research easy to run, inspect, and reproduce. PhD in Dynamic
Systems and Control, UT Austin.

- [**Afterimage**](https://github.com/oney-erge/Afterimage): run supported BF16 language models beyond GPU memory and reproduce inference measurements.
- [**LocalDeploy**](https://github.com/oney-erge/LocalDeploy): choose, run, and measure local models on your own hardware.
- [**YBM**](https://github.com/oney-erge/YBM): carry out supervised computer tasks with approvals and receipts.
- [**AgentGymnasium**](https://github.com/oney-erge/AgentGymnasium): evaluate AI agents on visual physics challenges.
- [**Creature Lab**](https://github.com/oney-erge/Creature-Lab): design and diagnose simulated robot bodies and controllers.
- [**SegCraft**](https://github.com/oney-erge/SegCraft-Semantic-Segmentation): train and run semantic segmentation on images and video.
